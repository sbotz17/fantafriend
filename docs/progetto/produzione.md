# Produzione — Fantafriend

- **Pubblicazione**: npm run deploy (Wrangler) sul dominio di produzione.
- **Dati**: Neon PostgreSQL con Drizzle.
- **Backup**: backup PostgreSQL verificato.
- **Rollback**: ripristinare la versione precedente del codice; per i dati, solo su autorizzazione di Andrea con
  backup verificato e prova su copia.

Registro delle pubblicazioni: data, cosa e' cambiato, esito della verifica.
