Leggi `docs/progetto/`, la struttura del repository e `git log --oneline -10`.

1. Se `docs/progetto/indice.md` non esiste, crealo con aree, file chiave e documenti di riferimento.
2. Aggiorna i nodi toccati dalle ultime modifiche (max 50 righe, con `Ultima revisione`).
3. Segnala documenti obsoleti o file non mappati.

Non modificare codice.
